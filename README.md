## Operações Morfológicas

Este projeto consiste em uma série de scripts em Python que utilizam a biblioteca OpenCV para aplicar operações morfológicas em imagens.

## Scripts

Os scripts são:
- `operadores-morfológicos.py`: Aplica operação morfológica de erosão em uma imagem.
- `dilatacao.py`: Aplica operação morfológica de dilatação em uma imagem.
- `erosao-seguida-de-dilatacao.py`: Aplica operação morfológica de abertura em uma imagem.
- `abertura.py`: Aplica operação morfológica de abertura em uma imagem.
- `fechamento.py`: Aplica operação morfológica de fechamento em uma imagem.
- `gradiente-morfologico.py`: Aplica operação morfológica de gradiente em uma imagem.
- `top-hat.py`: Aplica operação morfológica de top-hat em uma imagem.
- `black-hat.py`: Aplica operação morfológica de black-hat em uma imagem.
- `abertura-seguida-de-dilatacao.py`: Aplica operação morfológica de abertura seguida de dilatação em uma imagem.
- `fechamento-seguido-de-erosao.py`: Aplica operação morfológica de fechamento seguida de erosão em uma imagem.
